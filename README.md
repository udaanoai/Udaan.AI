# UDAAN AI Website — V1

A single-page, responsive MVP website for UDAAN AI.

## Run locally
Open `index.html` in a browser.

## Publish for free
1. Create a GitHub repository.
2. Upload `index.html`.
3. Import the repository into Netlify.
4. Deploy.

Before launch, replace `hello@udaan-ai.com` with the real UDAAN contact email.
